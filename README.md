# Restaurant App - Itsuki

Aplicación móvil desarrollada con **Ionic** y **Angular** que permite a los usuarios consultar el menú de un restaurante, administrar un carrito de compras y realizar pedidos de manera sencilla.

## Funcionalidades

- Visualizar el menú de comidas.
- Agregar productos al carrito.
- Modificar la cantidad de productos.
- Eliminar productos del carrito.
- Consultar el resumen del pedido.
- Realizar el proceso de compra.

## Tecnologías utilizadas

- Ionic
- Angular
- TypeScript
- HTML
- CSS
- Android Studio

## Conexión

La aplicación consume una API REST desarrollada en Spring Boot para obtener la información del restaurante y gestionar los pedidos.
